# NeonPanel

پنل مدیریت اتصال VLESS — پیاده‌سازی خالص پایتون، بدون باینری خارجی.
روش‌های فعال: **WebSocket (WS)** و **TCP خام**؛ هر دو واقعی و با تست E2E.

## ✨ ویژگی‌ها

- 🔌 **VLESS/WS** — روی همان پورت وب (توسط پل اتوماتیک در لبه) — مناسب Railway/VPS
- 🔌 **VLESS/TCP** — پورت مستقل `TCP_PORT` — مناسب VPS (یا Railway TCP Proxy)
- 🚀 بدون Xray باینری — دیپلوی سریع، سازگار با Railway/Docker
- 🔗 لینک نامحدود: سقف حجم (GB)، سرعت (Mbps)، حد IP هم‌زمان، انقضا
- 📊 شمارش ترافیک + اتصال‌های زنده
- 👥 گروه‌های ساب (چند لینک در یک آدرس، رمزدار)
- 📱 صفحهٔ ساب + QR + فرمت raw/sing-box/clash
- 🎨 رابط ساده مینیمال + تم دارک/لایت

## 🚀 دیپلوی (Railway)

1. ریپو را دیپلوی کن (Docker)
2. وریبل `ADMIN_PASS` = رمز قوی (خالی = رندوم در لاگ)
3. دامنهٔ عمومی بساز
4. (اختیاری) برای TCP خام: پورت TCP Proxy در Railway بساز و با `TCP_PORT` ست کن

**لینک پیش‌فرض خودکار ساخته می‌شود** — اگر هیچ کانفیگی نباشد، پنل یک `default` می‌سازد تا همیشه یک لینک زنده وجود داشته باشد.

## 🔑 استفاده

1. `https://<دامنه>` → رمز از `ADMIN_PASS`
2. «لینک جدید» → نام + سقف‌ها → بساز
3. لینک `vless://` را در V2RayNG/Hiddify/Streisand بگذار
