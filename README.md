# ⚡ NeonPanel

پنل مدیریت VPN نسل جدید — ریمیکس کامل با UI تیره/نئونی، دوزبانه (فارسی/انگلیسی) و **تشخیص خودکار دامنه**.

> ریمیکسِ: https://github.com/rezanorouzi900/-

## ✨ امکانات

- 🎯 **بدون تنظیم دستی**: دامنه از هدر `Host` خودکار شناسایی می‌شود
- 🔗 ۴ پروتکل: VLESS / VMess / Trojan (WebSocket) + Shadowsocks + Reality
- 📱 سابسکریپشن ۴ فرمت: base64 / Clash / Sing-box / JSON + هدر `Subscription-Userinfo`
- 📊 نمودار مصرف ۳۰ روزه + اکانتینگ ترافیک هر ۶۰ ثانیه
- 📟 پروکسی تلگرام (MTProto) با یک کلیک روشن/خاموش
- 🛡️ JWT + bcrypt + ریت‌لیمیت + هدرهای امنیتی
- 🌐 فارسی (RTL، فونت وزیرمتن) + English — سوییچ لحظه‌ای
- 🐳 Docker + Railway با دیپلوی تک‌دکمه‌ای

## 🚀 دیپلوی ۳ دقیقه‌ای (Railway)

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?repo=https://github.com/rezanorouzi900/NeonPanel)

1. روی دکمهٔ بالا بزن
2. متغیرها را ست کن (حداقل `ADMIN_USER` و `ADMIN_PASS`)
3. تمام — پنل روی `https://<your-app>.up.railway.app` بالا است

## 🐳 Docker

```bash
cp .env.example .env   # مقادیر را ویرایش کن
docker compose up -d    # پنل روی پورت 8080
```

## 🖥️ اجرای لوکال

```bash
./scripts/install.sh   # venv + pip + xray
python -m app.main     # http://localhost:8080
```

## 🔑 ورود اولیه

- یوزرنیم: از `ADMIN_USER` (پیش‌فرض `RXpanel`)
- پسورد: از `ADMIN_PASS` — اگر خالی باشد، پسورد رندوم ساخته و **فقط یک‌بار** در لاگ چاپ می‌شود
- بعد از ورود حتماً از «تنظیمات ← تغییر رمز» عوضش کن

## ❓ FAQ فارسی (۳۰ سؤال)

<details>
<summary>باز کن</summary>

1. **پنل بالا نمی‌آید؟** لاگ `.data/logs/` + `PORT` اشغال نباشد + `/api/health` را چک کن.
2. **لینک‌ها کار نمی‌کنند؟** اول `/api/domain` را چک کن؛ اگر localhost بود یعنی دامنه عمومی شناسایی نشده (پشت Railway/Tunnel ببر).
3. **ساب در کلاینت آپدیت نمی‌شود؟** کش کلاینت؛ URL را دستی رفرش کن؛ توکن عوض نشده باشد.
4. **یوزر وصل نمی‌شود ولی لینک سالم است؟** enabled؟ انقضا؟ سقف حجم؟ ساعت سرور؟
5. **پسورد ادمین یادم رفت؟** روی سرور: `python -m app.reset_admin --user RXpanel` (یا بدون آرگومان برای admin).
6. **چطور دامنه شخصی بزنم؟** CF tunnel با `CF_TUNNEL_TOKEN` + DNS در Cloudflare، یا `PUBLIC_DOMAIN`.
7. **پورت 8080 اشغال است؟** `PORT=8081` در `.env`.
8. **Reality چیست و کی لازم است؟** وقتی WS/443 اختلال دارد؛ پورت 8443 + SNI (`www.microsoft.com`).
9. **MTProto روشن نمی‌شود؟** پورت 4433 آزاد باشد؛ `RAILWAY_TCP_PROXY_DOMAIN` را ست کن.
10. **بکاپ را کجا نگه دارم؟** بیرون از سرور؛ فایل zip شامل db + سکرت‌هاست.
11. **مهاجرت به سرور جدید؟** نصب تازه + ریستور zip از «تنظیمات ← بازگردانی».
12. **چطور یوزر عمده بسازم؟** `python scripts/bulk.py users.csv` (ستون‌ها: name,quota_gb,expires_days).
13. **حجم‌ها دقیق نیست؟** اکانتینگ هر ۶۰ ثانیه؛ تا ۲٪ خطا طبیعی است.
14. **تانل quick هر بار URL عوض می‌کند؟** بله؛ برای ثابت از token استفاده کن.
15. **امنیت پنل؟** JWT + ریت‌لیمیت + هدرها؛ پنل را بدون TLS مستقیم روی اینترنت نگذار (همیشه پشت Railway/Tunnel/ریورس‌پروکسی).
16. **لاگ‌ها کجاست؟** `.data/logs/` (xray/tunnel/mtproto/app جدا).
17. **چطور آپدیت کنم؟** بکاپ → pull → rebuild → ریستور در صورت نیاز.
18. **دیتابیس خراب شد؟** از آخرین zip ریستور کن.
19. **فارسی‌سازی اپ‌ها؟** ساب و نام‌ها فارسی را پشتیبانی می‌کنند (fragment انکد می‌شود).
20. **چرا QR خوانده نمی‌شود؟** طول لینک زیاد؛ در نور کم؛ فایل را دانلود و تست کن.
21. **Clash خطا می‌دهد؟** `fmt=clash` را در مرورگر باز کن؛ YAML باید با `proxies:` شروع شود.
22. **سینگ‌باکس ایمپورت نمی‌کند؟** `fmt=singbox` + نسخه اپ ≥ 1.8.
23. **Hiddify؟** از دکمهٔ «باز کردن در کلاینت» صفحهٔ یوزر.
24. **V2RayNG؟** لینک خام یا ساب base64.
25. **Streisand (iOS)؟** ساب singbox.
26. **NekoBox؟** ساب base64.
27. **چرا پینگ بالاست؟** سرور/لوکیشن؛ url-test در Clash خودش بهترین را انتخاب می‌کند.
28. **رایتل/همراه اول فرق دارد؟** نه در سطح پنل؛ اگر اختلال اپراتوری بود Reality/MTProto را امتحان کن.
29. **چند یوزر می‌توانم بسازم؟** محدودیت نرم‌افزاری نیست؛ بالای ۵۰۰ یوزر SQLite را به Postgres ببر.
30. **چطور پیشنهاد/باگ بدهم؟** Issue در ریپوی گیت‌هاب.
