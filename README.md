# NeonPanel

پنل مدیریت اتصال VLESS — رلهٔ خالص پایتون، بدون وابستگی به باینری خارجی. وب‌سوکت را در لبه دریافت و خودش پروتکل VLESS را رمزگشایی و اتصال TCP را برقرار می‌کند.

## ✨ ویژگی‌ها

- 🔌 VLESS روی WebSocket (تک‌پروتکل، ساده)
- 🚀 بدون باینری خارجی — دیپلوی سریع، سازگار با Railway/Docker
- 🔗 لینک نامحدود: سقف حجم (GB)، سرعت (Mbps)، حد IP هم‌زمان، انقضا
- 📊 شمارش ترافیک + اتصال‌های زنده
- 👥 گروه‌های ساب (چند لینک در یک آدرس، رمزدار)
- 📱 صفحهٔ ساب + QR + فرمت raw/sing-box/clash
- 🎨 رابط ساده و مینیمال، فارسی RTL

## 🚀 دیپلوی (Railway)

1. ریپو را دیپلوی کن (یا Docker)
2. وریبل اضافه کن: `ADMIN_PASS` = رمز قوی (خالی = رندوم در لاگ اولین اجرا)
3. دامنهٔ عمومی بساز — تمام.

## 🔑 استفاده

1. `https://<دامنه>` → رمز از `ADMIN_PASS`
2. «لینک جدید» → نام + سقف‌ها → بساز
3. لینک `vless://` را در کلاینت V2RayNG/Hiddify/Streisand بگذار

## ⚙️ متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASS` | رمز داشبورد | خالی = رندوم در لاگ |
| `SECRET_KEY` | کلید امضای سشن | خودکار |
| `DATA_DIR` | مسیر داده | `/data` |
| `PORT` | پورت گوش‌دادن | 8080 |
