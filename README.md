# ⚡ NeonPanel v3

پنل VPN نسل سوم — **رلهٔ VLESS خالص پایتون** (روش px-panel، بدون Xray باینری).

> روش: همان معماری اثبات‌شدهٔ px-panel — خود پنل پروتکل VLESS را در پایتون پیاده کرده و روی WebSocket از لبه (Railway TLS) سرو می‌دهد. یک hop کمتر = سریع‌تر.

## ✨ ویژگی‌ها
- 🔌 **فقط VLESS روی WebSocket** (تک‌پروتکل، بدون دردسر)
- 🚀 بدون Xray/پروسس فرزند — دیپلوی سریع، اتصال سریع‌تر
- 🔗 کانفیگ نامحدود: سقف حجم GB + سرعت Mbps + حد IP هم‌زمان + انقضای روز
- 📊 شمارش بایت واقعی + اتصال‌های زنده
- 👥 گروه‌های ساب (چند کانفیگ در یک لینک، رمزدار شدن)
- 📱 صفحهٔ ساب HTML زیبا + QR + فرمت‌های raw/sing-box/clash
- 🌐 فارسی RTL + دوزبانه لحظه‌ای

## 🚀 دیپلوی (Railway — ۲ دقیقه)

1. Fork کن
2. Railway → New Project → از ریپوی خودت دیپلوی کن
3. وریبل‌ها: `ADMIN_PASS` = رمز قوی (خالی = رندوم در لاگ اولین اجرا)
4. دامنهٔ عمومی بزن — تمام. لینک‌ها خودکار با همان دامنه ساخته می‌شوند.

## 🔑 استفاده

1. `https://<app>.up.railway.app` → رمز `ADMIN_PASS`
2. «کانفیگ جدید» → نام + سقف‌ها → بساز
3. لینک `vless://` یا ساب را در V2RayNG/Hiddify/Streisand بگذار — همین!

## ⚙️ متغیرها

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASS` | رمز داشبورد | خالی = رندوم در لاگ |
| `SECRET_KEY` | کلید امضای سشن | خودکار |
| `DATA_DIR` | مسیر داده (Volume وصل کن) | `/data` |
