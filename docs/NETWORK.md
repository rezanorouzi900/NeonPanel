# معماری شبکه — NeonPanel

## دیاگرام

```
              ┌─────────────┐
              │   Client    │  V2RayNG / Hiddify / TG
              └──────┬──────┘
                     │ 443 (TLS در لبه)
           ┌─────────▼─────────┐
           │ Railway / CF edge │
           └─────────┬─────────┘
                     │ HTTP → 127.0.0.1:8080
           ┌─────────▼─────────┐
           │  FastAPI (panel)  │── / روت داشبورد
           │  + WS router      │── /v9e.. → xray (vless)
           └─────────┬─────────┘── /t49.. → xray (vmess)
                     │           ── /s0a.. → xray (trojan)
           ┌─────────▼─────────┐
           │   Xray-core       │── 8443 reality ──→ net
           │   stats :10085    │── 8388 ss ──────→ net
           └───────────────────┘
           ┌─────────┐  ┌──────────┐
           │ cf side │  │ mtproto  │ (4433, جدا)
           └─────────┘  └──────────┘
```

## پورت‌ها

| سرویس | پورت | پروتکل | توضیح |
|---|---|---|---|
| پنل + API + ساب + WS | 8080 (`$PORT`) | HTTP/WS | TLS در لبه ترمینیت می‌شود |
| Reality | 8443 | TCP+Reality | SNI: `www.microsoft.com` |
| Shadowsocks | 8388 | TCP | `SS_PORT=0` = غیرفعال |
| MTProto | 4433 | TCP | مستقل، toggle از UI |
| Xray API | 127.0.0.1:10085 | gRPC | فقط لوکال — اکانتینگ ترافیک |

## تشخیص خودکار دامنه (۶ اولویت)

1. `PUBLIC_DOMAIN` (override دستی ادمین)
2. هدر `X-Forwarded-Host`
3. هدر `Host`
4. `RAILWAY_PUBLIC_DOMAIN`
5. کش تانل Quick (5 دقیقه)
6. fallback: `localhost` + بنر هشدار زرد در UI

قوانین: هاست فقط با regex معتبر پذیرفته می‌شود، sanitize (حذف کاراکتر غیرمجاز، سقف ۲۵۳)، لیست سفید اختیاری `ALLOWED_HOSTS`.

## مسیرهای WS

در نصب اول، برای هر پروتکل path رندوم ۱۲ کاراکتری ساخته و در `.data/paths.json` + جدول `settings` ذخیره می‌شود. ریکوئست غیر-Xray روی این مسیرها → 400 (بدون فینگرپرینت).

## تانل کلودفلر

- `CF_MODE=token`: تانل پایدار با `CF_TUNNEL_TOKEN` (DNS خودکار)
- `CF_MODE=quick`: تانل موقت — URL از لاگ cloudflared پارس و در داشبورد نمایش داده می‌شود
- وضعیت (وصل/قرمز + URL) در داشبورد و صفحهٔ دامنه

## امنیت شبکه

- هیچ پورتی جز 8080/8443/8388/4433 (در صورت فعال بودن) روی 0.0.0.0 listen نمی‌شود
- Xray Stats API فقط 127.0.0.1
- لاگ IP واقعی پشت تانل از `CF-Connecting-IP` (فقط لاگ، نه احراز هویت)
- ریت‌لیمیت: لاگین ۵ تلاش/۵ دقیقه (قفل ۱۵ دقیقه)؛ ساب ۳۰/دقیقه

## ماتریس عیب‌یابی

| علامت | علت محتمل | اقدام |
|---|---|---|
| `/api/health` → 502 | اپ بالا نیست / PORT اشتباه | لاگ app؛ `PORT`؛ پورت آزاد |
| لینک WS → 400 | path اشتباه | `paths.json` با لینک مقایسه شود |
| ساب → 404 | توکن اشتباه / یوزر off | توکن تازه از صفحهٔ یوزر |
| ساب خالی (۰ بایت) | همهٔ پروتکل‌ها off / منقضی | وضعیت یوزر + `SS_PORT` |
| Reality handshake fail | SNI/کلید | `reality_pub` با کانفیگ چک شود |
| MTProto → connecting… | پورت بسته / سکرت | TCP پورت؛ سکرت ۳۲hex |
| Tunnel URL نیست | cf خطا / توکن بد | لاگ tunnel؛ `CF_MODE` |
| دامنه localhost | بدون هدر Host عمومی | پشت proxy واقعی ببر |
| مصرف صفر ولی یوزر فعال | stats API قطع | Xray up؟ 10085 لوکال؟ |
| لاگین 429 | قفل IP | ۱۵ دقیقه صبر |
| بکاپ خراب | دانلود ناقص | حجم فایل + verify |
